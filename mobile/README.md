# App móvil Flutter

Esta carpeta contiene una versión inicial de la app móvil para el proyecto de riesgo de diabetes.

## Requisitos

- Flutter instalado y configurado.
- El backend corriendo en http://127.0.0.1:8000.

## Ejecutar

```bash
cd mobile
flutter pub get
flutter run
```

La app usa el mismo flujo que la web: completar perfil, enviar un check-in y ver resultados e historial.
